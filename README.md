# BobaScore

A local-first Android app for ranking bubble tea shops through pairwise comparisons.

## Run locally

1. Install Flutter stable and an Android emulator or connect an Android device.
2. From this repository, run `flutter pub get`.
3. Check targets with `flutter devices`.
4. Launch with `flutter run -d <device-id>`.

The Android application ID is `com.mycompany.bobascore`. Firebase is intentionally
not wired into this starter yet, and photos will remain local on-device when that
feature is added.
